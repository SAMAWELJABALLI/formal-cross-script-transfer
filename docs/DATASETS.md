# Datasets

This repository **does not redistribute any corpus text**. All five corpora are public GitHub repositories
maintained by their authors. The code downloads them, at pinned commits, into `data/raw/` and builds
`data/examples.jsonl` locally. `data/` is git-ignored.

## Rebuilding the corpus

```bash
python -m formal_si.data.fetch      # git clones into data/raw/<name>, moves each clone to its pinned commit,
                                    # writes data/raw/fetch_log.json (commit, licence files found)
python -m formal_si.data.build      # -> data/examples.jsonl with grouped train/dev/test splits
sha256sum data/examples.jsonl       # expected 52d9e7b970f3d48fc70d910cd6a2d6f5bd20a50702d757bdad50432deb607b59
```

On 2026-11-05 this procedure reproduced the corpus used for the archived runs **byte for byte**. The rebuilt
file had the same SHA-256 and the same 55,689 rows. If an upstream repository is rewritten or removed, the
fingerprint makes the difference visible.

Splits are grouped. Near-duplicate texts and all script renderings of one sentence share a group, and a group
never crosses splits. `reports/data_audit.json` gives per-source counts, label distributions and duplicate
statistics. It contains counts only.

## What is and is not in this repository

| Item | In repository? | Why |
| --- | --- | --- |
| Corpus text (any source) | No | Redistribution rights are unclear or restricted, see the table above |
| `data/examples.jsonl`, `data/contrast_negation.jsonl` | No | They contain corpus sentences. Rebuild them locally |
| Embedding caches (`cache*/emb.npy`, `texts.json`) | No | Derived from corpus text, about 660 MB, regenerable (Level B) |
| Neural-transliteration outputs (`cache_neural_translit/*pairs*.json`, `full_input_map.json`) | No | Transliterations of corpus sentences |
| Native-speaker negation review sheet (`negation_review_100.csv`) | No | Contains corpus sentences, some offensive. Also unvalidated, so it supports no claim |
| Example-sentence tables (`examples.tex`, `v3_error_examples.*`, `v3_phenomena.*`) | No | Contain corpus sentences. They are regenerated by Level B from the local corpus |
| Gold labels and sentence-group ids (`runs/*/gold.json`) | Yes | Label strings and opaque ids such as `narabizi:913` or `tsac:g25`, with no text. Needed to score the archived predictions |
| Predictions (`runs/**/predictions*.jsonl`) | Yes | Predicted label strings only. `scripts/verify_artifacts.py` checks this |
| Encoding and transliterator metadata (`artifacts/encoding_meta`, `artifacts/neural_translit`) | Yes | String counts, timings, character error rates, training losses. No text |

An automated scan of every file in the repository found no Arabic-script corpus text and no free-text fields in
the archived results. The only Arabic characters are a short circumfix in the negation-review README, the
transliteration rules in `src/formal_si/text/normalize.py`, and synthetic phrases in `tests/`. Raw social-media
text may contain personal data. Users who rebuild the corpus are responsible for handling it according to the
upstream terms and applicable data-protection law.
